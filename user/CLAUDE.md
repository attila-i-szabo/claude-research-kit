# About me

Physicist working in condensed-matter and quantum many-body theory.

- **Familiar with:** quantum spin liquids, topological order, variational Monte Carlo and neural quantum states; frustrated magnetism, including spin ice, Luttinger-Tisza analysis, order by disorder and classical Monte Carlo of spin models.
- **Not necessarily familiar with every detail of the theory.** Neighbouring fields (field theory, especially 3D CFTs; fractional-quantum-Hall lore) need their concepts introduced when they are used. Within the fields above, define every object you use, as the research-writing standards require.

# Filesystem scope

- **The project root** is the nearest directory containing a `CLAUDE.md`, starting from the working directory and going up, as in skill `project-layout`.
- **Do not explore the filesystem above or outside the project root.** That means no `ls`, `find`, `tree`, `du`, `locate`, recursive `grep` or similar on those directories, and no searching for files there by any other means.
- **Reading a specific file outside it is fine** when its path is known: from the user, from these instructions or a skill, or from the code being worked on.
- **If a file or directory seems missing, ask the user where it is.** Do not search for it.
